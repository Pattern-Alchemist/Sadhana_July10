## Troubleshooting Production Issues

### Mantras Not Showing
**Fix:** Verify DATABASE_URL in Vercel environment variables
1. Go to Vercel Dashboard
2. Select project
3. Settings → Environment Variables
4. Confirm DATABASE_URL is set

### Voice Not Working
**Fix:** Verify HTTPS and browser permissions
1. Check HTTPS is enabled (should be automatic)
2. Browser settings → Microphone permissions
3. Clear cache and hard refresh
4. Try different browser

### Slow Performance
**Fix:** Check Vercel Analytics
1. Go to Vercel Analytics dashboard
2. Review: Web Vitals
3. Check: Database queries
4. Optimize: If needed
